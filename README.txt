Домашнее задание 13 — Box Model и отступы

Файлы:
- index.html — страница
- style.css — оформление

Что сделано по чек-листу:
1. Карточка использует box-sizing: border-box. Её ширину можно проверить в DevTools.
2. Класс .container имеет max-width и margin: 0 auto.
3. На странице показаны два блока с margin. В тексте объяснено, что такое Margin Collapse и как его избежать.

Как открыть:
1. Распакуй ZIP.
2. В VS Code нажми File → Open Folder.
3. Выбери папку css-homework13-simple.
4. Открой index.html и запусти через браузер.
